Co_cofe 系统垃圾清理 · 使用说明
================================

一句话：只清临时文件和回收站，你的文档、照片、程序和日志一个都不动。


一、界面
--------
  ┌ 可释放空间 ──────────────────────────────┐
  │  大字是合计大小，右边是文件数/回收站项数   │
  └──────────────────────────────────────────┘

  三行分类，点一下勾选/取消勾选：
    用户临时文件      %TEMP%（一般最占地方）
    Windows 临时文件  C:\Windows\Temp（需要管理员权限）
    回收站            所有驱动器，空的时候自动不勾选

  「只清理 [1 天] [3 天] [7 天] [全部]」
    只清理 N 天以前的临时文件。默认 1 天，避免删掉正在安装/下载用的临时文件。
    切换后会自动重新扫描。

  三个按钮：
    重新扫描            重新统计当前勾选分类
    以管理员身份运行    提权重启，解锁 Windows 临时文件；提权后按钮显示「已以管理员运行」
    立即清理            弹确认框 → 清理 → 自动重新扫描并显示「已释放 X」

  窗口右下角版本号；鼠标悬停在三行分类和三个按钮上都有说明。


二、为什么 Windows 临时文件要管理员
------------------------------------
  C:\Windows\Temp 的权限只给 SYSTEM 和管理员，普通用户删不掉，这是系统限制。
  没提权时那一行会显示「跳过 / 需要管理员权限」，按钮下方也有一行提示。
  点中间那个「以管理员身份运行」→ 跳过 UAC → 程序以管理员重启，那一行就解锁了。

  提权后想回到普通模式：关掉窗口重新双击即可（程序不会自己降权）。


三、安全规则（和网上流传的 lj.bat 的区别）
------------------------------------------
  不做的事：
    · 不全盘扫描 C 盘，只进上面那三个位置
    · 不删任何 .log 日志、.old 备份、prefetch 预读取
    · 不碰文档、图片、视频、桌面、下载、程序目录
    · 不跟随目录联接（ReparsePoint），不会"跑"到别的目录去删

  做的事：
    · 只删 N 天以前的临时文件（默认 1 天）
    · 正在被占用的文件自动跳过，不报错、不强删
    · 带"系统"属性的文件跳过
    · 清理完只回收已经变空的子目录，临时目录本身保留
    · 每次清理都写日志，逐条记录删了什么


四、日志与配置
--------------
  %LOCALAPPDATA%\Co_cofe系统垃圾清理\cleanup-时间戳.log   清理记录
  %LOCALAPPDATA%\Co_cofe系统垃圾清理\window.txt           窗口位置/大小/是否最大化

  删掉 window.txt 就会恢复默认窗口。日志可以随时删。


五、窗口尺寸
------------
  拖动窗口边框或四角可以调整大小，也可以双击标题栏最大化。
  布局会跟着拉伸：卡片撑满宽度，按钮/进度条固定在底部。
  最小尺寸有限制，不会缩到挤在一起。
  关闭时会记住位置和大小，下次打开原样还原（换了显示器且不在屏幕内时会回到屏幕中间）。


六、命令行版（可选，随安装包一起装上）
--------------------------------------
  Co_cofe系统垃圾清理-命令行.exe

    --dry-run        只预览，不删任何东西
    --days N         只清理 N 天以前的文件，0 表示不限
    --keep-recycle   不动回收站
    --yes            跳过确认（适合做计划任务）

  例：Co_cofe系统垃圾清理-命令行.exe --dry-run --days 3


七、常见问题
------------
  Q：会不会删掉我桌面上没用的文件？
  A：不会。程序只认那三个临时位置，桌面/文档/下载根本不在扫描范围内。

  Q：清完发现某个程序出问题了？
  A：临时文件本来就是可丢弃的，正常软件会自动重建。如果确实异常，
     看日志里删了什么（第四节的路径），一般重启程序即可。

  Q：为什么可释放空间很小？
  A：默认只清 1 天以前的文件；想更彻底可以把「只清理」切到「全部」。

  Q：需要联网吗？
  A：不需要。程序不联网、不装服务、不开机启动，只写上面第四节那两个文件。

  Q：卸载后会留下什么？
  A：卸载会删程序目录、快捷方式和注册表项；%LOCALAPPDATA% 下的日志和
     窗口配置会保留，想彻底清除手动删掉那个文件夹即可。
